# Обект План

Приложение за строителен обект: чертежи, планиране, количества и автоматични скици на армировката —
толкова просто, че да го ползва и човек, който не чете чертежи.

Работи на телефон, таблет (iOS и Android) и в браузър. Направено с Expo / React Native.

## Какво има

| Екран | Какво прави |
|---|---|
| **Роли** | Клиент, Работник, Ръководител — всеки вижда само своето |
| **Обект** | Сградата по етажи от кота ±0.00 до покрива, с готовност в % |
| **Покажи** | Стъпка по стъпка: скица „така трябва да изглежда“, „какво да провериш“, къде е в сградата, бутон „Отбележи готово“ |
| **Чертежи и снимки** | Качване на PDF и снимки по етажи и специалности; увеличение с два пръста |
| **График** | Задачи по етажи, статуси с цветове, закъснелите в червено |
| **Количества** | Бетон (по клас, с бетоновози), армировка (по диаметър), кофраж, зидария, тухли, мазилка — по етаж и общо; експорт за Excel |
| **Елемент** | Автоматична скица на армировката, спецификация на прътите, етапи на изпълнение |
| **Разкрой** | Как да се нарежат 12-метровите пръти с най-малко отпадък |

Елементи: колона, греда, плоча, шайба, стълбище, зидария.

> Приложението смята **количества** по готов конструктивен проект. То не оразмерява конструкцията —
> това остава отговорност на инженер-конструктор.

## Пускане

```bash
npm install
npx expo start          # после: w = браузър, или сканирайте QR кода с Expo Go
```

## Проверки

```bash
npm test                # тестове на сметките (бетон, армировка, разкрой)
npm run typecheck
npx expo lint
```

## Структура

- `src/lib/calc.ts` — всички формули (бетон, армировка, снаждане, кофраж, зидария)
- `src/lib/cutting.ts` — разкрой на прътите
- `src/lib/labels.ts` — текстове с прости думи и „какво да провериш“
- `src/components/rebar-sketch.tsx` — автоматичните скици
- `src/app/` — екраните

Данните се пазят на устройството (работи без интернет). Планът за развитие е в [PLAN.md](PLAN.md).
